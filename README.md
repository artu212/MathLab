# MathLab

O **MathLab** é uma plataforma matemática desenvolvida como projeto acadêmico, com o objetivo de reunir diferentes ferramentas de cálculo, estudo e prática em um único ambiente.

## Funcionalidades

Atualmente, o projeto conta com recursos como:

- Calculadora básica
- Calculadora científica
- Funções matemáticas
- Operações com matrizes
- Análise combinatória
- Probabilidade
- Exercícios matemáticos
- Histórico de cálculos
- Temas visuais

## Tecnologias

- HTML
- CSS
- JavaScript

## Status

Em desenvolvimento.

Novas funcionalidades, melhorias e correções serão adicionadas ao longo do desenvolvimento do projeto.

## Objetivo

O projeto foi desenvolvido como parte dos estudos acadêmicos e também como forma de praticar conceitos de desenvolvimento web, lógica de programação e organização de software.
